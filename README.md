# MSED — Minecraft Structured Environment Data

MSED is a Fabric-based engine instrumentation framework for Minecraft that records 
tick-aligned, multi-modal trajectories combining structured engine state with visual 
observations.

This repository is the public release of MSED, presented at IEEE CoG 2026.

## Status

Code release in progress. Full source and documentation coming soon.
